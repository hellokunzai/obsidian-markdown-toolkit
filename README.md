# Markdown Toolkit

> 在 Obsidian 里把图表、思维导图、流程图**可视化编辑**，再一键写回纯文本；附带一套编辑器工具栏、文件浏览器增强和附件管理工具。

- 当前版本：0.18.0
- 最低支持 Obsidian：1.4.16
- 桌面端与移动端均可使用（无需联网、无需账号、无内购）

---

## 它能做什么

插件围绕「Markdown 本身才是数据」这一理念：所有图形都存储为笔记里的**围栏代码块**，可以纳入版本控制、跨平台迁移、被任何 Markdown 工具读取。一共四块能力：

### 1. 图形可视化编辑器（核心）

在笔记里用代码块写图表，点一下代码块就能打开**画布式编辑器**，拖拽排版后自动把结果写回代码块源码。内置 **11 种**图表：

`mindmap`（思维导图）· `flowchart`（流程图）· `sequence`（时序图）· `class`（类图）· `state`（状态图）· `er`（实体关系图）· `gantt`（甘特图）· `pie`（饼图）· `gitGraph`（Git 图）· `timeline`（时间线）· `ishikawa`（鱼骨图）

- 自研 SVG 渲染 + dagre 自动布局，**不依赖**外部 CDN/网络。
- 在画布上拖动节点；位置会被记进代码块内的一行注释，下次打开仍保持你摆好的样子，且其他渲染器会忽略这行注释。
- 代码块就是数据：可见即可改，改完即纯文本，永不锁定。

相关命令：

| 命令 | 说明 |
|---|---|
| 插入思维导图代码块 | 插入一个空的 `mindmap` 代码块 |
| 插入流程图代码块 | 插入一个空的 `flowchart` 代码块 |
| 插入图表… | 从 11 种里挑一种插入 |
| 把选中的大纲转成思维导图 | 选中多级列表，一键生成思维导图 |
| 编辑光标处的图形 | 光标在代码块内时打开可视化编辑器 |

### 2. 编辑器工具栏

可自定义的格式化工具栏（默认 40+ 按钮，支持拖拽子菜单）：

- **格式刷**：把一段文字的格式一键套用到另一段。
- **下划线**：切换下划线。
- **文本批处理**：去空行、合并/拆分行、去重、加前后缀、行号、首尾空格、空白折叠、表格 ↔ 列表转换、按规则提取等一组工具。
- **对齐**：左对齐 / 居中 / 右对齐 / 两端对齐（通过代码块内联样式实现，纯文本可读）。
- **双色板**：字体颜色、背景颜色各一支取色面板。
- **全屏专注模式**：把编辑区铺满屏幕，隐藏侧栏与状态栏干扰。

相关命令：`切换格式刷` · `下划线` · `字体颜色` · `背景颜色` · `全屏专注模式`。

### 3. 文件浏览器增强

- **隐藏规则**：按「精确名称 / `startsWith::` 前缀 / `endsWith::` 后缀」隐藏文件浏览器里的条目（例如隐藏 `attachments` 文件夹或 `.obsidian` 类条目）；可忽略大小写；可顺手把命中项加入 Obsidian「已排除文件」列表（从搜索、关系图谱、反链中隐身）；状态栏显示当前隐藏数量。
- **手动排序**：为文件浏览器里的条目自定义显示顺序，可一键重置回字母序。

### 4. 附件管理

- **附件文件夹模板**：用变量（`${noteFileName}`、`${folderPath}`、`${originalFileName}`、`${date:YYYYMMDDHHmmss}`）决定附件落在哪里，支持相对当前笔记或仓库根。
- **文件名模板**：重命名/保存附件时套用模板。
- **特殊字符处理**：把文件名/文件夹名里的特殊字符替换或删除，避免同步与跨平台踩坑。
- **同步重命名 / 移动**：重命名或移动笔记时，其附件文件夹一并改名/搬走，所有链接自动更新。
- **重名分隔符**：粘贴同名文件时自动加分隔符 + 计数器，直到找到空闲名。
- **空文件夹策略**：笔记搬走后，空附件文件夹可保留 / 删除 / 连同空父目录一起删除。
- **孤立附件清理**：删除笔记时，把它带出来的孤儿附件送进回收站（可恢复）。

## 安装

本插件**尚未上架 Obsidian 社区插件市场**，暂时用以下方式安装：

### 方式一：手动安装

1. 到 [Releases](https://github.com/hellokunzai/obsidian-mindforge/releases) 下载最新版的三个文件：`main.js`、`manifest.json`、`styles.css`。
2. 在 vault 里新建文件夹 `<你的仓库>/.obsidian/plugins/markdown-toolkit/`（**文件夹名必须与插件 id `markdown-toolkit` 完全一致**）。
3. 把三个文件放进去，重启 Obsidian，到「设置 → 第三方插件」里启用 **Markdown Toolkit**。

> ⚠️ 插件 id 与文件夹名必须同名，否则插件无法正确读取/同步配置。

### 方式二：通过 BRAT 安装（Beta）

1. 先安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件。
2. BRAT 里「Add a beta plugin」，填入仓库地址：`hellokunzai/obsidian-mindforge`。
3. 启用后即可在第三方插件列表看到本插件，更新也由 BRAT 负责。

## 设置

插件设置分为五个页签：

| 页签 | 内容 |
|---|---|
| **常规** | 流程图默认方向、思维导图展开方向、是否记住拖动节点位置、编辑器打开方式 |
| **工具栏** | 增删按钮、拖拽调整子菜单与顺序 |
| **隐藏规则** | 要隐藏的条目、忽略大小写、启用隐藏、加入已排除文件列表、状态栏指示 |
| **手动排序** | 开启手动排序、重置自定义顺序 |
| **附件** | 附件文件夹与文件名模板、特殊字符处理、同步重命名/移动、重名分隔符、空文件夹策略、孤立附件清理 |
