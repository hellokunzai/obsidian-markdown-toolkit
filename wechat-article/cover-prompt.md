# 《我做了个 Obsidian 插件：图表写进纯文本》封面图提示词

> 配色与正文主题「雾蓝 slate」保持一致，让封面和排版视觉统一。

## 主体元素
Obsidian 笔记界面 + 从代码块里「长」出来的思维导图/流程图（纯文本与可视化之间的连接感）。

## 主封面 Prompt（概念向）
**中文：**
> 微信公众号文章封面图，横版 2.35:1。画面中心是一台笔记本上的 Obsidian 笔记，笔记里的代码块正「生长」出一张半透明的思维导图，连线轻盈飘起；背景是干净的浅蓝灰渐变（#f0f4f8 → #e2e8f0），漂浮着半透明的小节点和代码符号。扁平插画风格、干净留白、明亮专业，主体突出，右上角留出放标题文字的空白。无真实人脸。

**English：**
> WeChat article cover, horizontal 2.35:1. Center: an Obsidian note on a laptop, a fenced code block growing into a translucent mind map with light floating connectors; clean light slate gradient (#f0f4f8 → #e2e8f0) background with translucent nodes and code glyphs. Flat illustration, clean minimal, bright professional, subject prominent, empty space top-right for title text. No real human faces. --ar 2.35:1

## 变体 B：极简抽象
**中文：**
> 极简公众号封面，横版。中央一个代码块图标被一圈思维导图节点轻轻环绕，单一主色 #64748b（雾蓝灰）配大量留白。扁平几何风，高级感。

**English：**
> Minimal WeChat cover, horizontal. Center: a code block icon gently surrounded by mind map nodes, single accent color #64748b with lots of whitespace. Flat geometric, premium feel. --ar 2.35:1
