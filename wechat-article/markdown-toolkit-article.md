# 我做了个 Obsidian 插件：图表写进纯文本，Git 能管、手机能看、换电脑不丢

# 🔔 开篇导语

事情是这样的。我在 Obsidian 里画图，最常用的两种方式：要么截图贴进笔记，要么导出 png 丢在 attachments 里。截图一时爽，回头想改一个节点名字，得重新画、重新导出、重新贴。图一多，笔记就慢慢变成一堆改不动的「图片坟墓」。

后来我想，能不能让图和表继续活在 Markdown 里——还是那段文本，只是给它配个可视化编辑器？于是有了 Markdown Toolkit 这个插件。

> 📷 配图建议：左右对比图，左边是「截图流程图躺在 attachments 文件夹」，右边是「代码块里的 flowchart 文本 + 画布编辑器打开」，中间画个箭头

---

# 📖 它是什么

Markdown Toolkit 是一款 Obsidian 社区插件，当前版本 0.21.0，最低支持 Obsidian 1.4.16。桌面端和移动端都能用，不联网，不要账号，没有内购，MIT 协议开源。

一句话说清楚：在笔记里可视化编辑图表、思维导图、流程图等 12 种图形，改完自动写回纯文本；同一套画布也能编辑带公式的 Markdown 表格。另外还顺手带了编辑器工具栏、文件浏览器增强和附件管理几块工具。

> 💡 核心前提：图表和表格继续以纯文本存在笔记里，编辑器只是给这份文本配的一层操作界面，不是另存一份副本。

---

# 🚀 核心功能

## 1. 图形可视化编辑器：12 种图，画完写回代码块

在笔记里用代码块写图表，点一下就在画布上打开。拖动排版后，结果写回代码块源码。内置 12 种图形：思维导图、流程图、时序图、类图、状态图、实体关系图、甘特图、饼图、Git 图、时间线、鱼骨图、柱状图。

几个我自己在用的点：

- 自研 SVG 渲染加 dagre 自动布局，不依赖外部 CDN，也不用联网。
- 节点位置记进代码块里的一行注释，下次打开还是你摆好的样子，别的渲染器读到这行会跳过。
- 渲染失败不会整块变空白，而是把源码显示出来并说明是哪种图形出的问题。
- 画布上能拖节点、改名字、加子节点和兄弟节点、撤销重做、缩放，五种节点形状（矩形、圆角、圆形、菱形、六边形）。

相关命令：`插入思维导图代码块`、`插入流程图代码块`、`把选中的大纲转成思维导图`、`编辑光标处的图形`。

> 📷 配图建议：思维导图代码块 + 打开后的画布编辑器截图，红框标出「写回源码」那行注释

## 2. 表格编辑器：Markdown 表也能算公式

阅读视图和实时预览里，插件会接管 Markdown 表格，给每张表套上画框。在格子里写 `=sum(B2:B4)` 就会算出结果，格子里显示值，源码里留公式。

公式支持 `sum`、`avg`、`count`、`max`、`min`，也支持 `B2:B4` 这样的区域引用和 `+ - * /` 括号算式。写错了显示成 `#REF!` 这类值，不会把整张表渲染崩。

编辑器是电子表格式的：字母列标加数字行号、滚动吸顶、拖拽选范围、方向键和 Tab 移动、双击输入、拖填充柄续填序列。画框角上能一键导出 CSV 或 Markdown。

## 3. 编辑器工具栏：40+ 按钮，还能自己排

一条可自定义的格式化工具栏，默认 40 多个按钮。我平时用得最多的是三块：

- 格式刷：把一段文字的格式套到另一段。
- 文本批处理：15 个工具，去空行、去重、加前后缀、加行号、表格和列表互转等。
- 双色板：字体色和背景色各一支取色面板，面板里能用吸管取屏幕上的颜色。

另外还有全屏专注模式、对齐（左中右两端）、图表子菜单、分组标题。手机上它会自动隐藏 Obsidian 自带的那条键盘工具条，只留插件这一条——装上就生效，不用设置。

## 4. 文件浏览器增强（默认关）和附件管理（默认关）

这两个模块默认关，在「功能模块」页签打开才生效：

- 文件浏览器增强：按名称、前缀或后缀隐藏条目，比如藏起 `attachments` 或 `.obsidian`；还能给文件夹手动定顺序。
- 附件管理：附件落在哪、叫什么名都能用变量模板定；重命名或移动笔记时，附件文件夹跟着搬，链接自动更新；删笔记时把孤儿附件送进回收站，还能恢复。

# 🛠 技术上是怎么做的（简单说一点）

图表这块最麻烦的是「改完怎么回到纯文本」。我的做法：编辑器改的就是代码块里的源码，永远只有这一份，没有第二副本，也不存在需要导出的中间格式。位置信息塞进代码块的一行注释里，既不影响别的 Markdown 工具读取，也不污染正文。

渲染和排版全在本地完成。布局用 dagre，SVG 是自己画的，所以离线、无 CDN 依赖。

# 如何安装 / 更新

新用户：在 Obsidian「设置 → 第三方插件」里搜 Markdown Toolkit，直接装。

老用户或者想装 Beta：

- 手动装：去 [Releases](https://github.com/hellokunzai/obsidian-markdown-toolkit/releases) 下载 `main.js`、`manifest.json`、`styles.css` 三个文件，放进 `<仓库>/.obsidian/plugins/markdown-toolkit/`，文件夹名要跟插件 id `markdown-toolkit` 完全一致。
- 走 BRAT：装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 后填仓库 `hellokunzai/obsidian-markdown-toolkit`，以后更新交给它。

> ⚠️ 文件夹名必须和插件 id 同名，这点我踩过坑，配不对就一直读不到设置。

# ❓ 常见问题

Q：手机能用吗？
A：能。插件标了 `isDesktopOnly: false`，iOS 和 Android 都跑得起来，画布和表格都支持双指捏合缩放。

Q：需要联网吗？
A：不需要。所有计算本地完成，不发起任何网络请求。

Q：会不会跟我现有的图表渲染冲突？
A：代码块里那行位置注释，别的渲染器读到会直接跳过，不影响它们渲染。

Q：功能太多会不会卡？
A：五个模块在「功能模块」页签都能单独开关，只开你要的就行。

# 📋 全文总结

做这个插件的出发点其实很朴素：图不该是笔记的终点，截图贴进去就改不动了；它应该是笔记的一部分，跟着正文一起进 Git、一起跨平台、一起被检索。

我反复坚持两条底线：一是数据始终以纯文本存在，控制权在用户手里；二是同步不该是个黑盒，不联网、不依赖外部服务。
